01 — Supervised Learning

Learns from labeled input–output pairs

01 Linear Regression Supervised

Fits a straight line through data to predict a continuous numeric output. Minimizes the sum of squared differences between predicted and actual values (OLS). Extends to multiple features via multiple linear regression.

Tabular
Use Cases House price prediction, sales forecasting, stock trend analysis
02 Logistic Regression Supervised

Despite the name, this is a classification algorithm. Applies a sigmoid function to a linear combination of features to produce class probabilities between 0 and 1. Fast, interpretable, and a strong baseline model.

Tabular NLP
Use Cases Email spam detection, medical diagnosis, credit default prediction
03 Decision Tree Supervised

Recursively splits data by choosing the feature and threshold that best separates classes, maximizing information gain or reducing Gini impurity. Produces a readable, flowchart-like model that requires little preprocessing.

Tabular
Use Cases Loan approval, customer churn prediction, medical triage
04 Random Forest Supervised

Trains hundreds of decision trees on random data and feature subsets (bagging), then combines predictions by majority vote or averaging. Dramatically reduces overfitting compared to a single tree and provides feature importance scores.

Tabular CV
Use Cases Fraud detection, feature importance ranking, clinical risk scoring
05 Support Vector Machine Supervised

Finds the hyperplane that maximizes the margin between classes. The kernel trick (RBF, polynomial) maps data to higher dimensions to handle non-linear boundaries. Works well in high-dimensional spaces with limited training samples.

Tabular CV NLP
Use Cases Image classification, text categorization, bioinformatics
06 Convolutional Neural Net Supervised

Uses learned spatial filters (kernels) that slide across images to detect local patterns in a hierarchy: edges → textures → objects. Pooling layers provide translation invariance. The dominant architecture for visual recognition tasks.

CV NLP
Use Cases Medical imaging (tumor detection), autonomous driving, face recognition
07 RNN / LSTM Supervised

Processes sequences step by step with a hidden state as memory. LSTM gates (input, forget, output) control what information persists across time steps, solving the vanishing-gradient problem that limits plain RNNs on long sequences.

NLP Tabular
Use Cases Time-series forecasting, speech recognition, machine translation (pre-2017)

02 — Unsupervised Learning

Finds structure in data without labels

08 K-Means Clustering Unsupervised

Partitions data into k clusters by iteratively assigning each point to its nearest centroid, then recomputing centroids until convergence. The number k must be chosen ahead of time; the elbow method and silhouette score help guide that choice.

Tabular CV
Use Cases Customer segmentation, image color quantization, anomaly detection
09 Principal Component Analysis Unsupervised

Finds orthogonal directions of maximum variance via eigendecomposition of the covariance matrix. Projecting data onto the top components reduces dimensionality while preserving the most information, aiding visualization and preprocessing.

Tabular CV NLP
Use Cases Exploratory data analysis, noise reduction, Eigenfaces (face recognition)

03 — Generative / Self-supervised

Learns to generate or model data distributions at scale

10 Transformer Generative

Uses multi-head self-attention to model relationships between all positions in a sequence simultaneously — no recurrence needed. Pre-trained on massive corpora via next-token prediction, then fine-tuned for downstream tasks. Foundation of all modern LLMs.

NLP CV Gen AI
Use Cases ChatGPT, Claude, BERT (search), ViT (image classification), DALL·E
